# 🧠 UrbanMind

UrbanMind is an AI-powered community platform designed to help people report civic issues, connect with their local community, and discover nearby resources through an intuitive and modern interface.

## 🌐 Live Demo

**Deployed Application:**
https://community-hero-980507869557.asia-southeast1.run.app

---

## 📖 Overview

UrbanMind empowers citizens to engage with their communities by making it easy to:

* Report local civic issues
* Explore community initiatives
* Discover nearby services and resources
* Interact through a clean, responsive interface
* Leverage AI to improve community engagement

---

## ✨ Features

* 🏙️ Community issue reporting
* 🤖 AI-assisted interactions
* 📍 Location-based community resources
